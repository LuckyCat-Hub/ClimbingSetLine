# ClimbingSetLine

一个 3D 攀岩线路规划系统，使用 React Three Fiber 构建可视化攀岩墙，支持多墙管理、多种岩点类型和交互式线路设计。

## 功能特点

### 攀岩墙管理
- 支持创建和管理多面攀岩墙
- 每面墙可独立设置角度（0°、15°、30°、45°）
- 支持纵向和横向扩展墙布局
- 可调整墙的宽度和位置

### 岩点系统
系统支持 6 种主要岩点类型：

| 类型 | 描述 | 颜色 |
|------|------|------|
| Jug (大握) | 适合初学者的大型抓握点 | 红色 |
| Sloper (斜面) | 需要用手掌贴合的斜面岩点 | 蓝色 |
| Crimp (窄边) | 需要用手指扣住的窄边岩点 | 绿色 |
| Pinch (捏握) | 需要拇指和其他手指捏合的岩点 | 橙色 |
| Pocket (扣点) | 带有凹槽可以放置手指的岩点 | 紫色 |
| Edge (平边) | 平整的边缘岩点 | 青色 |

每种类型包含 4-5 种不同的子类型，例如 Jug 包含碗形、椭圆、牛角、平面、双孔等形状。

### 交互功能
- 3D 轨道相机控制（旋转、缩放、平移）
- 点击选择岩点
- 添加/删除岩点
- 自定义岩点颜色

## 技术栈

- **框架**: Next.js 16
- **UI**: React 19
- **3D 渲染**: Three.js + React Three Fiber + Drei
- **语言**: TypeScript
- **样式**: Tailwind CSS 4

## 快速开始

### 环境要求
- Node.js 18+
- npm / yarn / pnpm

### 安装

```bash
cd demo
npm install
```

### 开发

```bash
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000) 查看应用。

### 构建

```bash
npm run build
```

### 生产部署

```bash
npm start
```

## 使用说明

### 创建岩点
1. 在左侧面板选择岩点类型（如 Jug）
2. 选择具体的子类型（如"碗形 Jug"）
3. 点击 3D 场景中的墙面位置添加岩点

### 选择岩点
- 点击场景中的岩点可将其选中
- 选中的岩点会高亮显示

### 调整岩点
- 选中岩点后，可在右侧面板调整其属性
- 支持修改颜色、旋转角度、缩放大小

### 管理多面墙
- 使用顶部工具栏添加新墙（纵向或横向）
- 选择墙后可调整其角度
- 支持删除非底层墙壁
