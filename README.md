# 液丘 (Liquid Mound)

一个 2D/3D 攀岩线路规划系统，支持多墙管理、多种岩点类型和交互式线路设计。

## 功能特点

### 双模式编辑
- **3D 模式**：多角度攀岩墙立体可视化，支持旋转、缩放，模拟真实岩壁视角
- **2D 模式**：简化平面视图，木质洞洞板背景，适合现场快速定线

### 岩点系统
系统支持 6 种主要岩点类型，每种包含 4-5 种不同的子类型：

| 类型 | 描述 | 颜色 |
|------|------|------|
| Jug (大握) | 适合初学者的大型抓握点 | 红色 |
| Sloper (斜面) | 需要用手掌贴合的斜面岩点 | 蓝色 |
| Crimp (窄边) | 需要用手指扣住的窄边岩点 | 绿色 |
| Pinch (捏握) | 需要拇指和其他手指捏合的岩点 | 橙色 |
| Pocket (扣点) | 带有凹槽可以放置手指的岩点 | 紫色 |
| Edge (平边) | 平整的边缘岩点 | 青色 |

### 交互功能

#### 添加模式
- 点击画布空白区域添加新岩点
- 点击已有岩点位置选中它（不重复创建）
- 选中岩点后可进行拖拽移动、尺寸调整、旋转
- 支持撤销/重做操作

#### 选择模式
- 点击岩点选中它
- 点击空白区域取消选择
- 选中岩点后可进行拖拽移动、尺寸调整、旋转、删除
- 切换到选择模式后左右边栏自动隐藏

#### 截图功能
- 一键截取当前画布
- 支持下载为 PNG 图片
- 支持系统分享功能

## 技术栈

- **框架**: Next.js 16
- **UI**: React 19
- **3D 渲染**: Three.js + React Three Fiber + Drei
- **截图**: html2canvas
- **语言**: TypeScript
- **样式**: Tailwind CSS 4

## 快速开始

### 环境要求
- Node.js 18+
- npm / yarn / pnpm

### 安装

```bash
cd demo
npm install
```

### 开发

```bash
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000) 查看应用。

### 构建

```bash
npm run build
```

### 生产部署

```bash
npm start
```

## 使用说明

### 2D 模式

1. 进入首页后选择 **2D 模式**
2. 左侧工具栏：
   - 选择模式（黄色高亮）/ 添加模式（蓝色高亮）
   - 截图按钮
   - 返回首页
3. 左侧边栏（添加模式显示）：选择岩点父类
4. 右侧边栏（添加模式显示）：
   - 子类型选择
   - 选中岩点的属性控制（尺寸、旋转）
5. 中间画布：
   - 点击空白区域添加岩点
   - 点击已有岩点选中它
   - 拖拽移动岩点
   - 双击删除岩点
6. 底部工具栏：撤销/重做

### 3D 模式

1. 进入首页后选择 **3D 模式**
2. 使用轨道相机控制（旋转、缩放、平移）
3. 点击墙面位置添加岩点
4. 点击岩点选中它，调整属性
